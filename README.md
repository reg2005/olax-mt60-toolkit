# OLAX MT60 Toolkit

Разблокировка **поддерживаемой ревизии OLAX MT60** с Linux, Windows и macOS,
резервные копии каждого устройства и установка исправленного ядра через штатную
веб-панель. Интерфейс команд и инструкция на русском.

**Статус: экспериментальный выпуск 0.1.0.** Исходная процедура разблокировки
проверена на двух модемах через macOS. Этот переносимый установщик и новые OTA ZIP
ещё не проходили полный цикл на заводском устройстве. Тесты на компьютере не
подтверждают работу USB-драйверов, recovery и питания конкретного модема.

## Что поддерживается

Только `t60_extchg_k61`, MediaTek MT6761 (`hwcode 0x717`), eMMC 7 GiB,
точные заводские boot, recovery и boot0 из [таблицы совместимости](docs/compatibility.md).
Маркировки «MT60» недостаточно. Неизвестный образ останавливает процедуру.
Параметра `--force` нет.

Исправление устраняет две записи отрицательного значения калибровки Rfg,
связанные с нагрузкой `pmic_thread` и `gauge_coulomb_t`. Внутренний CV ограничен
4,35 В. Ramdisk остаётся заводским. Это не подтверждение исправности внешней
зарядной схемы и не обещание времени работы аккумулятора.

Комплект устанавливает только ядро. Дополнительной админки, VPN, APK и настроек
других модемов в нём нет. Разблокировка — отдельная USB-процедура;
**ZIP для штатной панели сам загрузчик не разблокирует.**

## Перед началом

1. Подготовьте ОС по [инструкции](docs/platforms.md), распакуйте source/toolkit ZIP
   в отдельную папку. Нужны Python 3.12 x64, `adb`, libusb/UsbDk и Интернет для
   первой загрузки закреплённых зависимостей.
2. Работайте с одним модемом. Отключите другие MediaTek-устройства от USB.
   Установите исправный совместимый аккумулятор, зарядите минимум до 50% и
   обеспечьте стабильное USB-питание.
3. Подключитесь к его Wi-Fi или USB-сети. Узнайте адрес штатной панели:
   обычно `192.168.0.1` по Wi-Fi, `192.168.42.1` по USB. Выключите на компьютере
   VPN, блокирующий локальные адреса. Обычная доступность сайта через VPN
   не доказывает доступность root ADB к роутеру.
4. Для каждого модема выделите **новую приватную папку вне репозитория**.
   Не копируйте `seccfg`, CID, NVRAM или калибровки между устройствами.
   Держите вторую копию backup на другом носителе. Подготовьтесь к возможной
   потере настроек/данных: разблокировка не является безрисковой операцией.

## Linux / macOS

```sh
./olax.sh setup
./olax.sh enroll --host 192.168.0.1 --state "$HOME/.local/share/olax/unit01"
./olax.sh unlock --state "$HOME/.local/share/olax/unit01"
```

`enroll` запросит пароль **admin роутера**, откроет root ADB при необходимости,
проверит модель/прошивку и сохранит собственные разделы модема. Пароль остаётся
в памяти процесса. Резервные копии проверяются по SHA256 до и после чтения;
они содержат приватные идентификаторы и **не должны загружаться в GitHub**.
Полная копия пользовательского раздела не выполняется.

`unlock` сначала проверит копии и зависимости. Когда появится приглашение:

1. Отключите USB, выключите модем, выньте аккумулятор на несколько секунд.
2. Верните аккумулятор, оставьте USB отключённым.
3. Введите `UNLOCK` и Enter. Скрипт начнёт ждать сервисное устройство до 180 с.
4. Подключите USB. Reset не нажимайте и не удерживайте.
5. До результата не отключайте питание. При `SECTOR_VERIFIED` запись прочитана
   обратно: отключите USB и аккумулятор, верните аккумулятор, включите модем
   и восстановите подключение к Wi-Fi/USB-сети.
6. Подтвердите разблокировку после обычной загрузки:

```sh
./olax.sh verify --host 192.168.0.1 --state "$HOME/.local/share/olax/unit01"
```

Только `SUCCESS: разблокировка подтверждена после загрузки` означает завершение
этого этапа. `SECTOR_VERIFIED` отдельно не подтверждает загрузку Android.
При ошибке не повторяйте unlock и не удаляйте журнал: см. [восстановление](docs/recovery.md).

## Windows 10/11 x64

В `cmd.exe`, после установки [драйверов](docs/platforms.md#windows-1011-x64):

```bat
olax.cmd setup
olax.cmd enroll --host 192.168.0.1 --state "%LOCALAPPDATA%\OLAX\unit01"
olax.cmd unlock --state "%LOCALAPPDATA%\OLAX\unit01"
```

Физические действия такие же, как выше. После перезапуска:

```bat
olax.cmd verify --host 192.168.0.1 --state "%LOCALAPPDATA%\OLAX\unit01"
```

Для PowerShell используйте `./olax.ps1` и `$env:LOCALAPPDATA` вместо `%LOCALAPPDATA%`.
`olax.cmd` меняет ExecutionPolicy только для своего дочернего PowerShell-процесса,
не меняет системную политику и не устанавливает драйверы без ведома пользователя.

## Установка ядра

После успешного `verify` следуйте [OTA-инструкции](ota/README.md).
Сначала загрузите `01-CHECK-FIRST` и проверьте recovery log. Лишь затем —
`02-KERNEL-UNLOCKED-ONLY`. Веб-панель: локальное обновление → ZIP → обновить.
Контрольные суммы ZIP берите из того же GitHub Release.

После загрузки исправленного ядра:

```sh
./olax.sh verify --kernel --host 192.168.0.1 --state "$HOME/.local/share/olax/unit01"
./olax.sh close --host 192.168.0.1 --state "$HOME/.local/share/olax/unit01"
```

В Windows замените запускатель и путь по примерам выше. `close` выключает
диагностический root ADB через панель и проверяет, что соединение закрыто.
Выполняйте его также после диагностики/отмены работ, когда Android доступен.
Не оставляйте root ADB открытым в общей сети.

## Границы автоматизации

Скрипты не требуют Electron. Один Python CLI обеспечивает одинаковые проверки
на трёх ОС, `.sh`/`.cmd`/`.ps1` сохраняют аргументы и коды завершения.
Разрешения драйверов, пароль роутера и физический цикл питания требуют участия
человека. Нет общего скрипта «разблокировать любой MediaTek».

Запись разблокировки ограничена 512 байтами собственного `seccfg`: меняются только
lock word и его аппаратно вычисленная контрольная сумма. Проверяются hardware,
CID, GPT, полный 8 MiB seccfg и V4 encrypt/decrypt roundtrip. При неоднозначном
результате нет слепого повтора. Windows при зависании USB завершает дочерний
процесс и сохраняет неопределённый статус — автоматический откат в этом случае
не обещается. Подробнее в [ADR](docs/ADR-0001.md).

## Разработка

```sh
./olax.sh setup
.venv/bin/python scripts/test.py
cd ota
go test -race ./...
go vet ./...
```

В Windows Python среды: `.venv\Scripts\python.exe`. Offline-тесты не обращаются
к USB. [Сборка OTA из собственной stock-копии](ota/README.md#сборка).
Статус проверок — [docs/validation.md](docs/validation.md).

Код toolkit распространяется по GPL-3.0, с сохранением авторства mtkclient.
Происхождение зависимостей и firmware — [THIRD_PARTY.md](THIRD_PARTY.md).
