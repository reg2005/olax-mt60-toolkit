# Строгая совместимость

| Поле | Требуемое значение |
|---|---|
| Model/device | t60_extchg_k61 |
| SoC | MT6761 / hwcode 0x717 |
| Hardware tuple | subcode 0x8a00, hwver 0xca01, swver 0x200 |
| eMMC user geometry | 14942208 секторов по 512 байт |
| seccfg | V4, 8 MiB, исходный lock=1, runtime=0, verity=0 |
| boot | 32 MiB |
| boot SHA256 | `aea6db447c55a144af61ad9d28bff920b294c7e7f30605ebc8938175c8f3278d` |
| recovery SHA256 | `9a82a9dcb915efc78ce02e98c36fb45c82f087307882f7cb1585d8813b63ffc1` |
| boot0 SHA256 | `ce892a49b8811a097ad10e3b5b5401c7cfae3c5a77295223f123a3beec6deefc` |
| Исправленный boot SHA256 | `02b4337e75e0b088813b83280f93ef9fb908af96adcac5d1c0358884deba1feb` |

Полный CID и исходный seccfg SHA определяются отдельно для каждого устройства,
сохраняются локально и сверяются перед записью. В репозитории нет CID владельца.
Проверки security flags требуют подтверждённо отключённых SBC/SLA/DAA и прочих
защит именно этой ревизии. Универсальный обход для иных ревизий не предусмотрен.

Если guard не прошёл, не меняйте константы, чтобы «пропустить проверку»:
для другой ревизии нужен самостоятельный анализ образов и аппаратной схемы.
