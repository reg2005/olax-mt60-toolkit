# Проверки выпуска 0.1.0

Дата: 2026-10-15.

## Проверено локально на macOS

- Чистая Python 3.12 venv и установка закреплённых зависимостей.
- SHA256 upstream ZIP, исходного DA и всех файлов runtime; две явные USB-правки.
- 75 offline Python tests: границы flash, аппаратная идентичность, проверка V4,
  единственный сектор, неоднозначные ответы/rollback, запрет повтора, journal,
  неизвестное устройство и Windows timer cancellation. USB в тестах подменён.
- Go updater tests/race/vet, в том числе extraction полного известного boot
  (при `OLAX_TEST_BOOT`), и ARMv7 build.
- Python проверки whole-ZIP подписи и порчи payload/footer.
- Полное воспроизведение исправленного boot из точного stock-образа; совпадение
  с ранее аппаратно проверенным SHA256.

В CI без private firmware тест положительного extraction полного boot явно
пропускается, если `OLAX_TEST_BOOT` не указан. Отрицательные сценарии выполняются.
Сборщик OTA автоматически создаёт собственный проверенный fixture и выполняет
также положительный тест. CI не читает пользовательские дампы.

## Аппаратные границы

- Старая macOS-процедура разблокировки и само исправленное ядро проверены на двух
  t60_extchg_k61. Это не hardware-тест нового release workflow.
- Новые Linux/Windows запускатели, UsbDk и полная переносимая установка на свежем
  устройстве не проверены аппаратно.
- Stock web/recovery установка обоих ZIP ещё не выполнена на устройстве.
- Guarded stock restore проверен offline, аппаратная приёмка не завершена.
- Полный цикл зарядки, внешняя схема зарядника, точность gauge и срок работы
  батареи не сертифицированы этим исправлением.

Offline matrix: [GitHub Actions](https://github.com/reg2005/olax-mt60-toolkit/actions).
Состояние CI проверяется отдельно и не повышает hardware-статус релиза.
